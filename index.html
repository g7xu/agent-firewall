You see it before it happens.

When Claude Code goes to open a sensitive file, the firewall reads the file on your Mac first and stops the action. You get one plain popup, and nothing moves until you answer. If you don't answer, the answer is no.

Keep on my Mac has a local AI read the file instead, so the cloud agent only receives a short summary.

It finds sensitive files on its own.

A background scan checks your folders with no setup, all on your Mac. It reads text files, PDFs, Office documents, scanned pages and screenshots, and saves only labels and hashed file paths.

What it doesn't do yet.

  • It works on macOS, with Claude Code and agents that use an OpenAI-compatible API.
  • It can't see agents running on a vendor's own servers.
  • It recognizes sensitive data by patterns and file names, so a secret in a plainly named file can get through.
  • It's hackathon-stage software that raises the bar against mistakes and tricked agents. It isn't a complete security boundary.
